# 完整模板（复杂项目用）

## 什么时候用

默认用 SKILL.md 里的官方三段模板。项目满足任一条时改用这份：

- 有不能碰的数据、密钥或向量库
- 有踩过、必须交代给 agent 的坑
- 有明确的交付标准：测试全绿、改完必须重启

三条都不满足就不要用，多写的段落就是噪音。

## 与主模板的关系

以 SKILL.md 的主模板为准。这份只增加段落，不改官方三段的内容要求；两边冲突时按主模板。

## 完整示例

````markdown
# AGENTS.md

## 1. 开发规范

**代码规范**

- 数据层使用 sqlite3 裸 SQL，不引入 ORM
- 前端不使用框架和打包器
- 新增代码放对应目录，不跨层调用

**依赖管理**

- 用 uv 管理 .venv

**测试事项**

- 改完后端跑 compileall，改完前端跑 node --check，并在浏览器里验证

## 2. 常用命令

**启动**

```bash
wscript launch.vbs        # 启动服务
wscript stop_site.vbs     # 停止服务
curl http://127.0.0.1:8001/health    # 健康检查
```

**测试**

```bash
.venv/Scripts/python.exe -m compileall -q app judge scripts    # 后端语法检查
node --check web/app.js    # 前端语法检查
```

**新增**

```bash
.venv/Scripts/python.exe scripts/import_data.py    # 重新导入题库
```

## 3. 提交

- 不自动 git commit / push，除非明确要求

## 4. 边界

- data/ 下的题库、用例、提交记录是资产，批量删改前先备份
- 不动 .venv 和其他用户级配置

## 5. Tips

- 改完 .py 必须重启进程，--reload 不可靠
- 启动失败先看 logs/app.log
- 前端验收必须禁用缓存，否则看到的是旧样式
````
